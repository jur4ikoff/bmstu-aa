\ssr{ВВЕДЕНИЕ}

Цель лабораторной работы — разработать и реализовать программное обеспечение на языке python для извлечения данных из
текстовых файлов, полученных из pdf-файлов с применением библиотеки PyPDF2, с использованием регулярных выражений.
Были выделены следующие задачи:
\begin{enumerate}
	\item разработать регулярные выражения для решения задачи по варианту;
	\item реализовать функцию для поиска подстроки по варианту в pdf-файле с использованием разработанных регулярных выражений;
	\item реализовать программное обеспечение, принимающее на вход путь к pdf-файлу, использующее функцию из предыдущего пункта;
	\item проверить реализацию на приложенных к лабораторной работе файлах.
\end{enumerate}
