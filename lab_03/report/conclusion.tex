\ssr{ЗАКЛЮЧЕНИЕ}

В ходе выполнения лабораторной работы №3 была достигнута цель --- выявлено отсутствие участков программы, пригодных к распараллеливанию. В ходе лабораторной работы были выполнены следующие задачи:
\begin{enumerate}
	\item описаны два алгоритма поиска максимального элемента последовательности;
\item описаны реализации двух алгоритмов четырьмя графовыми моделями: графом управления, информационным графом, операционной историей, информационной историей;
\item указано отсутствие участков программы, пригодных для выполнения параллельно.
\end{enumerate}
